# Module briefs and materials

This directory is reserved for candidate module briefs and approved teaching
materials. Do not add numbered modules until the course outline is agreed.

For each candidate, copy
[`docs/templates/module-brief.md`](../../docs/templates/module-brief.md) into a
descriptively named module folder, follow
[`docs/authoring/module-research-playbook.md`](../../docs/authoring/module-research-playbook.md),
and mark unresolved research or owner decisions explicitly.

Keep approved module documentation, labs, and instructor materials together
within that module's folder. Keep reusable course-wide decisions and research
guidance in `docs/`.
